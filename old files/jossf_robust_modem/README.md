# Robust JOSS-F audio modem

This package preserves the interoperable JOSS-F transmitter and replaces only
receiver-side estimation and recovery logic.

## Standard-critical behaviour left unchanged

- 48 kHz waveform format
- ten 4096-sample linear chirps
- official four-pair Golay section
- 4096-point OFDM and 2048-sample cyclic prefix
- occupied bins 171 to 1024 inclusive
- standard pilot position every twentieth absolute OFDM block
- `spliced_seed_qpsk.npy` pilot values
- QPSK bit mapping
- Appendix-B interleaver
- Jossy-compatible WiMAX LDPC implementation, including its intentional
  unscaled-shift interoperability behaviour
- packet framing and transmitter padding

The transmitter waveform generated by `transmitter.py` is therefore unchanged
from the supplied implementation.

## Receiver changes

### Synchronisation and SFO

- energy-normalised chirp matched filtering
- each recovered chirp retains its absolute standard index from 0 to 9
- missing initial or intermediate chirps are permitted
- the following Golay section resolves whole-chirp timing ambiguity
- Huber robust regression estimates preamble origin and clock ratio
- a windowed-sinc arbitrary-ratio resampler corrects constant SFO

### Channel estimation and tracking

- the four Golay A/B estimates are combined robustly rather than blindly
- channel impulse responses are constrained to the cyclic-prefix duration
- OFDM pilot estimates are SNR-gated and blended with the previous estimate
- channel estimates are interpolated between Golay and subsequent OFDM pilots
- unused carriers estimate the received noise floor
- low-confidence/deep-null carriers receive correspondingly weak LDPC LLRs

### Ambiguity and recovery

- data-directed phase/timing correction is deliberately limited to a small,
  safe convergence region
- when LDPC decoding fails, a small bank of QPSK-rotation and timing hypotheses
  is scored using LDPC parity checks
- raw LDPC-stream preservation, header repair and best-effort text salvage remain
  available

## Files

- `modem.py` — shared standard and codec components
- `transmitter.py` — interoperable transmitter
- `receiver.py` — robust receiver
- `diagnostics.py` — six generated diagnostic figures
- `spliced_seed_qpsk.npy` — required agreed pilot; do not modify
- `payload.txt` — default example input
- `test_interop.py` — protocol/fingerprint tests
- `test_receiver_robustness.py` — deterministic receiver stress tests

## Installation

```bash
python -m pip install -r requirements.txt
```

## Use

Generate a transmission:

```bash
python transmitter.py
```

Decode a recording:

```bash
python receiver.py recorded.wav
```

Disable plots when running non-interactively:

```bash
python receiver.py recorded.wav --no-diagnostics
```

Run the checks:

```bash
python test_interop.py
python test_receiver_robustness.py
```

## Diagnostics

By default, decoding writes six plots to `diagnostic_plots/`:

1. absolute-index chirp fit and SFO residuals
2. corrected-signal spectrogram
3. Golay/pilot channel response and impulse response
4. raw and equalised constellations
5. CP timing score and LDPC convergence
6. pilot SNR, blend weights, residual drift and pilot-domain distortion

## Deterministic tests included

The supplied robustness test covers:

- clean end-to-end decoding
- one, three and four missing initial chirps
- SFO estimation at ±200 and ±500 ppm
- end-to-end decoding through a four-tap multipath channel, +350 ppm SFO and
  30 dB additive noise
- LDPC-guided recovery from a 90-degree QPSK rotation

These synthetic checks cannot fully represent phone AGC, clipping, loudspeaker
nonlinearity or a time-varying room. Real recordings should still be retained
for regression testing. Channels with significant energy beyond the 2048-sample
cyclic prefix cannot be perfectly equalised by any one-tap OFDM receiver.
